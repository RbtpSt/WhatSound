Política de privacidad de WhatSound

RoboTop Studios · Última actualización: 17 de octubre de 2026

WhatSound permite buscar, reproducir y compartir sonidos provenientes de servicios externos. Esta política explica el tratamiento de información al utilizar la aplicación.

Búsquedas y servicios externos

Para buscar y reproducir audios, la aplicación se conecta con proveedores externos. Estos pueden recibir las palabras buscadas, dirección IP y datos técnicos de conexión, sujetos a sus propias políticas de privacidad. El contenido de terceros está sujeto a las condiciones y derechos de sus respectivos titulares.

Información guardada en el dispositivo

WhatSound puede guardar localmente enlaces de sonidos que el usuario preparó para compartir y archivos de audio temporales para reproducción o envío. Se pueden eliminar estos datos desde las opciones de almacenamiento de Android o desinstalando la aplicación.

Publicidad y datos técnicos

WhatSound integra Google Mobile Ads (AdMob). Google y sus socios publicitarios pueden tratar identificadores del dispositivo o publicitarios, dirección IP, interacciones con anuncios, datos de uso y diagnóstico, de acuerdo con la configuración del servicio y el consentimiento que corresponda. La aplicación integra la plataforma de consentimiento de Google para consultar y mostrar opciones de privacidad cuando sea necesario. Consultá la política de privacidad de Google.

Cuentas y contenido compartido

No se requiere crear una cuenta de WhatSound. Si el usuario decide compartir un audio, Android permite seleccionar una aplicación receptora, como WhatsApp; el tratamiento posterior de ese contenido depende de la aplicación seleccionada.

Seguridad y conservación

La aplicación utiliza conexiones con servicios externos para búsquedas, audios y publicidad. Los datos conservados localmente pueden eliminarse desde el dispositivo. Los proveedores externos determinan sus propios plazos de conservación y medidas de seguridad.

Consultas sobre privacidad
